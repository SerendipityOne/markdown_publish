    2.文本操作

    2.1 stdout (标准输出)

    • >：将 stdout覆盖写入到文件（文件不存在则创建）。
    • >>：将 stdout追加写入到文件（文件不存在则创建）。
    • 2>：将 stderr覆盖写入到文件。
    • 2>>：将 stderr追加写入到文件。
    • &>或 >&：将 stdout和 stderr同时覆盖写入到文件。
    • &>>：将 stdout和 stderr同时追加写入到文件。
    • tee：从 stdin读取数据，同时写入到 stdout和一个或多个文件。常用选项 -a表示追加（类似 >>）。
    • /dev/null：特殊的“黑洞”设备文件，写入它的任何数据都会被丢弃。
    • /dev/stdout：标准输出设备文件。
    • /dev/stderr：标准错误设备文件。
    echo Hello World > peanuts.txt

    > 是一个重定向运算符，它允许我们改变标准输出的去向。它允许我们将 echo Hello World 的输出发送到文件而不是屏幕。如果文件不存在，它会为我们创建它。但是，如果它确实存在，它会覆盖它

    嗯，假设我不想覆盖我的 peanuts.txt。幸运的是，也有一个重定向运算符可以做到这一点：>>。

    $ echo Hello World >> peanuts.txt
$ cat peanuts.txt 
Hello World
Hello World

    2.2 stdin（标准输入）

    > cat peanuts.txt
Hello World
> cat < peanuts.txt > banana.txt

    2.3 stderr（标准错误）

    2.3.1 区分输出和错误

    2>：将 stderr覆盖写入到文件。

    > ls test1 2> error.log
> cat error.log  
ls: cannot access 'test1': No such file or directory

    2.3.2 丢弃错误

    > ls /non_existent_directory /etc/passwd > output.txt 2> errors.txt
> cat errors.txt 
ls: cannot access '/non_existent_directory': No such file or directory
> cat output.txt 
/etc/passwd

    2.3.3 同时重定向输出和错误

    > ls /non_existent_directory /etc/passwd &> all_output.txt
> cat all_output.txt 
ls: cannot access '/non_existent_directory': No such file or directory
/etc/passwd

    ls /non_existent_directory /etc/passwd > mixed.txt 2>&1（这是 &>的另一种写法）

    2>&1将错误信息和正常的输出信息就会混合在同一个输出流里

    $ ls /non_existent_directory /etc/passwd > mixed.txt 2>&1
$ cat mixed.txt     
ls: cannot access '/non_existent_directory': No such file or directory
/etc/passwd

    2.3.4 使用 tee命令

    tee：从 stdin读取数据，同时写入到 stdout和一个或多个文件。常用选项 -a表示追加（类似 >>）。

    &>和 >>是改变输出目的地的工具。tee是复制输出流的工具，它允许输出同时流向屏幕和文件（或多个文件），或者在管道中分流，这是单纯的重定向操作符无法做到的。当你需要“一鱼两吃”（既看到输出又保存它）或者在管道中“截流”时，tee就是最佳选择。

    > echo "This will be seen and saved" | tee tee_output.txt
This will be seen and saved
> cat tee_output.txt 
This will be seen and saved

    > echo "First line" | tee -a tee_output.txt
First line
> cat tee_output.txt 
This will be seen and saved
First line
> echo "Second line" | tee -a tee_output.txt
Second line
> cat tee_output.txt
This will be seen and saved
First line
Second line

    ❯ ls -l /etc | grep 'passwd'
-rw-r--r-- 1 root root       1823 Sep 19 10:44 passwd
-rw-r--r-- 1 root root       1827 Sep 19 09:39 passwd-
❯ ls -l /etc | grep 'passwd' | tee passwd_files.txt
-rw-r--r-- 1 root root       1823 Sep 19 10:44 passwd
-rw-r--r-- 1 root root       1827 Sep 19 09:39 passwd-
❯ cat passwd_files.txt
-rw-r--r-- 1 root root       1823 Sep 19 10:44 passwd
-rw-r--r-- 1 root root       1827 Sep 19 09:39 passwd-

    ❯ ls /non_existent_directory /etc/passwd 2>&1 | tee all_tee.txt
ls: cannot access '/non_existent_directory': No such file or directory

    不能使用&>

    ❯ ls /non_existent_directory /etc/passwd &> | tee all_tee.txt
zsh: parse error near `|'

    &>必须直接指向文件&>是一个组合重定向操作符（等同于 > file 2>&1），它要求后面必须直接跟文件名（或路径），不能直接连接管道符 |。

    例如：ls &> output.txt✅ 是合法的，但 ls &> | tee ...❌ 是语法错误。

    2.4 命令序列控制（;, &&, ||）、管道 (|) 以及 cut, grep, wc, sort, uniq等核心文本处理工具

    > ls -la /etc | less

    管道操作符 |，由一个竖线表示，允许我们获取一个命令的 stdout 并将其作为另一个进程的 stdin。在这个例子中，我们获取了 ls -la /etc 的 stdout，然后将其 管道 到 less 命令。

    2.4.1 命令序列控制（;, &&, ||）

    • ;：顺序执行命令，无论前一个命令成功与否。cmd1 ; cmd2
    • &&：仅当前一个命令成功（退出状态码为 0）时才执行下一个命令。cmd1 && cmd2
    • ||：仅当前一个命令失败（退出状态码非 0）时才执行下一个命令。cmd1 || cmd2

    编译一个 C 程序（假设文件叫 hello.c），如果编译成功 (&&)，则运行它；如果编译失败 (||)，则输出错误信息：

    > gcc hello.c -o hello && ./hello || echo "Compilation failed"
hello!!

    2.4.2 管道 (|)

    1. 查看进程：

      • 运行 ps aux。输出可能很长。

      • 使用管道将 ps aux的输出传给 grep，只显示包含你用户名（比如 user1）的行：ps aux | grep user1

      • 统计你运行的进程数量：ps aux | grep user1 | wc -l

    2. 文件内容处理：

      • 使用 cat查看 /etc/passwd文件内容：cat /etc/passwd
      • 使用管道只显示包含 /bin/bash的行（通常是普通用户）：cat /etc/passwd | grep '/bin/bash'或grep '/bin/bash' /etc/passwd
      • 统计系统上有多少个普通用户（使用 /bin/bash）：cat /etc/passwd | grep -c '/bin/bash'或 grep -c '/bin/bash' /etc/passwd

    2.4.3 cut, grep, wc, sort, uniq等核心文本处理工具

    2.4.3.1 cut和grep

    后续会介绍cut更加详细的用法

    1. 提取特定字段 (/etc/passwd)：

      • /etc/passwd文件使用冒号 :分隔字段。格式通常是：用户名:密码占位符(x):UID:GID:描述信息:家目录:登录Shell

        > cat /etc/passwd
root:x:0:0:root:/root:/bin/bash
daemon:x:1:1:daemon:/usr/sbin:/usr/sbin/nologin
bin:x:2:2:bin:/bin:/usr/sbin/nologin
sys:x:3:3:sys:/dev:/usr/sbin/nologin
sync:x:4:65534:sync:/bin:/bin/sync
...

      • 提取所有用户名（第1个字段）：cut -d':' -f1 /etc/passwd

        > cut -d ':' -f1 /etc/passwd
root
daemon
bin
...

      • 提取所有用户的 UID（第3个字段）：cut -d':' -f3 /etc/passwd

        > cut -d ':' -f3 /etc/passwd
0
1
2
3
...

      • 提取用户名和家目录（第1和第6个字段）：cut -d':' -f1,6 /etc/passwd

        > cut -d ':' -f1,6 /etc/passwd
root:/root
daemon:/usr/sbin
bin:/bin
...

    2. 结合 grep和 cut：

      • 提取使用 /bin/bash的用户的用户名：grep '/bin/bash' /etc/passwd | cut -d':' -f1
      • 提取 UID 大于等于 1000 的用户的用户名和 UID (提示：需要结合 sort或 awk，这里先用 cut准备数据)：cut -d':' -f1,3 /etc/passwd

    Linux sort 命令

    Linux uniq 命令

    1. 排序：

      • 创建一个文件 fruits.txt包含：apple, orange, banana, Apple, grape, banana(注意大小写和重复)。

      • 按字母顺序排序：sort fruits.txt

      • 按字母逆序排序：sort -r fruits.txt

      • 按字母顺序排序（忽略大小写）：sort -f fruits.txt

      > sort fruits.txt
apple
Apple
banana
banana
grape
orange
> sort -r fruits.txt
orange
grape
banana
banana
Apple
apple
> sort -f fruits.txt
apple
Apple
banana
banana
grape
orange

    2. 去重与计数：

      • 找出唯一的水果种类（需要先排序）：sort fruits.txt | uniq
      • 找出重复的水果：sort fruits.txt | uniq -d
      • 统计每种水果出现的次数：sort fruits.txt | uniq -c
      • 统计唯一水果的总数：sort fruits.txt | uniq | wc -l或 sort -u fruits.txt | wc -l
      > sort fruits.txt |uniq
apple
Apple
banana
grape
orange
> sort fruits.txt |uniq -d
banana
> sort fruits.txt |uniq -c
      1 apple
      1 Apple
      2 banana
      1 grape
      1 orange
> sort fruits.txt |uniq | wc -l
5
> sort -u fruits.txt | wc -l                                              
5

    2.4.4 综合练习

    创建一个模拟日志文件 access.log，包含类似以下内容（用 echo或编辑器创建）：

    192.168.1.1 - - [10/Sep/2024:14:32:10] "GET /index.html HTTP/1.1" 200 1234
10.0.0.5 - - [10/Sep/2024:14:32:15] "POST /login HTTP/1.1" 404 567
192.168.1.1 - - [10/Sep/2024:14:33:01] "GET /image.jpg HTTP/1.1" 200 98765
172.16.0.8 - - [10/Sep/2024:14:33:45] "GET /index.html HTTP/1.1" 200 1234
192.168.1.1 - - [10/Sep/2024:14:34:22] "GET /favicon.ico HTTP/1.1" 200 321

    • 任务 1： 找出所有状态码为 404的请求行。grep ' 404 ' access.log

    • 任务 2： 统计 index.html被访问的次数。grep -c 'GET /index.html' access.log

    • 任务 3： 提取所有访问的客户端 IP 地址（每行第一个字段）。cut -d' ' -f1 access.log

    • 任务 4： 找出访问量最大的前 3 个 IP 地址及其访问次数。

      • 提取 IP：cut -d' ' -f1 access.log
      • 排序：sort
      • 计数：uniq -c
      • 按访问次数（计数）逆序排序：sort -nr
      • 取前三：head -n 3
      > cut -d ' ' -f1 access.log | sort | uniq -c | sort -nr | head -3
      3 192.168.1.1
      1 172.16.0.8
      1 10.0.0.5

    • 任务 5： 统计不同 HTTP 方法 (GET, POST等) 的使用次数。(提示：提取方法字段，可能在引号内第一个单词，如 "GET或 "POST)。cut -d'"' -f2 access.log | cut -d' ' -f1 | sort | uniq -c

      • cut -d'"' -f2 access.log先按"分割

        > cut -d'"' -f2 access.log
GET /index.html HTTP/1.1
POST /login HTTP/1.1
GET /image.jpg HTTP/1.1
GET /index.html HTTP/1.1
GET /favicon.ico HTTP/1.1

    2.5 env（环境）

    1. 操作命令

      • 定义环境变量：

        • 方法 1：先定义本地变量，然后导出：VAR_NAME=value；export VAR_NAME
        • 方法 2：一步定义并导出：export VAR_NAME=value

      • 查看变量值： echo $VAR_NAME

        • 查看所有变量：
          • 所有变量（本地+环境）：set
          • 仅环境变量：env或 printenv

      • 取消设置变量： unset VAR_NAME

    2. 配置文件 (持久化)：

      • ~/.bashrc: 针对交互式、非登录 Bash Shell。当你打开一个新的终端窗口或标签页时，或者在一个已存在的 Shell 中启动一个新的 Bash 子 Shell (bash) 时，会读取此文件。这是配置个人环境变量、别名、函数最常用的文件。
      • ~/.bash_profile或 ~/.profile: 针对登录 Bash Shell。当你通过控制台、SSH 登录系统时，或者使用 bash --login/ bash -l启动 Shell 时，会读取此文件。通常用于设置登录时需要运行一次的环境（如 PATH添加）。
      • /etc/profile和 /etc/bash.bashrc(或 /etc/bashrc): 系统级别的配置文件，为所有用户设置环境。修改需要管理员权限 (sudo)。
      • ~/.bash_logout: 在注销登录 Shell 时执行。

    3. 重要环境变量：

      • PATH: 定义了 Shell 查找命令的目录列表。echo $PATH查看，通常用 PATH=$PATH:/new/directory添加新路径。
      • HOME: 当前用户的家目录路径。
      • USER/ LOGNAME: 当前用户名。
      • SHELL: 当前使用的 Shell 路径。
      • PWD: 当前工作目录。
      • OLDPWD: 上一个工作目录。

    2.5.1 基础变量操作

    1. 创建本地变量：

      • 打开终端。
      • 输入 MY_LOCAL_VAR="Hello Local World"。
      • 验证：echo $MY_LOCAL_VAR(应该输出 Hello Local World)。
      • 查看所有变量：set | grep MY_LOCAL_VAR(应该能看到它)。
      • 查看环境变量：env | grep MY_LOCAL_VAR(应该看不到它)。

    2. 创建环境变量：

      • 输入 export MY_ENV_VAR="Hello Global World"。
      • 验证：echo $MY_ENV_VAR(输出 Hello Global World)。
      • 查看环境变量：env | grep MY_ENV_VAR(现在应该能看到它)。

    3. 修改变量值：

      • 输入 MY_LOCAL_VAR="New Local Value"。
      • 输入 export MY_ENV_VAR="New Global Value"(或者 MY_ENV_VAR="New Global Value"因为已经是环境变量)。
      • 验证 echo $MY_LOCAL_VAR和 echo $MY_ENV_VAR。

    4. 取消设置变量：

      • 输入 unset MY_LOCAL_VAR。
      • 输入 unset MY_ENV_VAR。
      • 验证 echo $MY_LOCAL_VAR和 echo $MY_ENV_VAR(应该输出空行或报错 未找到变量)。

    2.5.2 作用域与继承

    1. 本地变量不继承：
      • 在父 Shell：MY_LOCAL_ONLY="Parent Local"
      • 启动一个子 Shell：输入 bash(注意提示符可能会变化)。
      • 在子 Shell 中：echo $MY_LOCAL_ONLY(应该输出空行，说明子 Shell 未继承父 Shell 的本地变量)。
      • 退出子 Shell：输入 exit。
    2. 环境变量可继承：
      • 在父 Shell：export MY_INHERITED="Parent Env"
      • 启动子 Shell：bash
      • 在子 Shell 中：echo $MY_INHERITED(应该输出 Parent Env，说明子 Shell 继承了父 Shell 的环境变量)。
      • 在子 Shell 中修改：export MY_INHERITED="Child Modified"
      • 在子 Shell 中验证：echo $MY_INHERITED(输出 Child Modified)。
      • 退出子 Shell：exit
      • 回到父 Shell：echo $MY_INHERITED(应该输出 Parent Env，说明子 Shell 的修改不影响父 Shell)。

    2.5.3 持久化配置 (~/.bashrc)

    1. 编辑 ~/.bashrc：

      • 使用你喜欢的文本编辑器打开 ~/.bashrc文件 (例如：nano ~/.bashrc, vim ~/.bashrc, gedit ~/.bashrc &)。

      • 在文件末尾添加以下内容：

        # My Custom Configuration
export MY_PERSISTENT_VAR="This will last!"
alias ll='ls -alF' # 创建一个常用别名

    2. 使配置生效：

      • 方法 1 (推荐)： 在当前终端执行 source ~/.bashrc或 . ~/.bashrc。这会立即加载修改后的配置到当前 Shell。
      • 方法 2： 关闭当前终端窗口并打开一个新的终端窗口。新的 Shell 启动时会自动读取 ~/.bashrc。

    3. 验证持久化：

      • 在新配置生效的 Shell 中：echo $MY_PERSISTENT_VAR(应该输出 This will last!)。
      • 输入 ll(应该执行 ls -alF，列出详细信息)。

    4. 修改 PATH：

      • 假设你有一个自定义脚本目录 ~/bin，你想把它加入 PATH。
      • 在 ~/.bashrc中添加：export PATH="$PATH:$HOME/bin"
      • source ~/.bashrc或开新终端。
      • 验证：echo $PATH(应该包含 :你的家目录/bin)。现在你可以直接运行 ~/bin目录下的脚本，无需指定完整路径。

    2.6 cut

    Linux cut命令

    让我们创建一个将要使用的文件。复制并粘贴以下命令；完成后，在“lazy”和“dog”之间添加一个 TAB 键（按住 Ctrl-v + TAB）。

    echo 'The quick brown; fox jumps over the lazy  dog' > sample.txt

    我们将学习的第一个命令是 cut 命令。它从文件中提取部分文本。

    按字符列表提取内容：

    cut -c 5 sample.txt

    这将输出文件中每一行的第 5 个字符。在本例中，它是“q”；请注意，空格也算作一个字符。

    cut -f 2 sample.txt

    -f 或字段标志根据字段剪切文本。默认情况下，它使用 TAB 作为分隔符，因此由 TAB 分隔的所有内容都被视为一个字段。您应该会看到“dog”作为输出。

    cut -f 1 -d ";" sample.txt

    这将把 TAB 分隔符更改为“;”分隔符，由于我们剪切的是第一个字段，结果应该是“The quick brown”。
