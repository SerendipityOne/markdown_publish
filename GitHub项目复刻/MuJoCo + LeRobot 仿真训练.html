    MuJoCo + LeRobot 仿真训练

    LeRobot 代码：https://github.com/huggingface/lerobot

    LeRobot 文档：https://huggingface.co/docs/lerobot/

    MuJoCo 文档：https://mujoco.readthedocs.io/

    WSL 官方文档：https://learn.microsoft.com/windows/wsl/

    当前选择

    你现在不想更新 Windows NVIDIA 驱动，所以先不要走 Isaac Sim。

    Isaac Sim:
依赖 NVIDIA 驱动、CUDA、Vulkan、RTX 图形栈。
当前 WSL2 检查结果只有 llvmpipe，GUI 不适合作为第一路线。

MuJoCo:
安装轻，GUI 依赖 OpenGL，比 Isaac Sim 更适合先打通机械臂仿真和 LeRobot 训练闭环。
训练侧可以按当前 566.36 驱动使用 PyTorch cu126，不需要升级到 cu128/cu130。

    当前目标：

    WSL2 Ubuntu 24.04
-> MuJoCo GUI 能打开
-> LeRobot 能安装
-> 用 torch 2.10.0+cu126 跑通仿真/数据/训练流程
-> 以后需要高保真 RTX 场景时再升级 Isaac Sim

    1.先检查 WSL2 图形环境

    如果从 Windows 终端直接进入 WSL2，通常 WSLg 会自动设置图形环境。

    如果你是通过 SSH 进入 WSL2，例如本机 127.0.0.1:2222，先手动补环境变量：

    export DISPLAY=:0
export WAYLAND_DISPLAY=wayland-0
export XDG_RUNTIME_DIR=/mnt/wslg/runtime-dir

    安装基础图形和编译依赖：

    sudo apt update
sudo apt install -y \
  git curl wget unzip build-essential cmake \
  mesa-utils libgl1 libglfw3 libglew2.2 \
  libosmesa6 libosmesa6-dev patchelf

    检查 OpenGL：

    glxinfo -B

    你现在的环境可能显示：

    OpenGL renderer string: llvmpipe
Accelerated: no

    这对 Isaac Sim 不够，但 MuJoCo 可以先用。MuJoCo GUI 如果打不开，再用 MUJOCO_GL=osmesa 跑 headless。

    2.创建 MuJoCo + LeRobot 环境

    不要继续用已有的 lerobot 环境。你当前那个环境是 Python 3.12，并且装了 torch 2.11.0+cu130，驱动不匹配，CUDA 不可用。

    新建一个干净环境：

    conda create -y -n lerobot_mujoco python=3.10
conda activate lerobot_mujoco

pip install -U pip setuptools wheel

    给 Conda 环境补 WSL2 的 CUDA 和 WSLg 环境变量。这样激活环境后可以直接用 nvidia-smi，SSH 进入 WSL2 时也能找到图形环境：

    mkdir -p "$CONDA_PREFIX/etc/conda/activate.d"
cat > "$CONDA_PREFIX/etc/conda/activate.d/wsl_cuda_gui.sh" <<'SH'
case ":${PATH:-}:" in
  *:/usr/lib/wsl/lib:*) ;;
  *) export PATH="/usr/lib/wsl/lib:${PATH:-}" ;;
esac
case ":${LD_LIBRARY_PATH:-}:" in
  *:/usr/lib/wsl/lib:*) ;;
  *) export LD_LIBRARY_PATH="/usr/lib/wsl/lib:${LD_LIBRARY_PATH:-}" ;;
esac
export DISPLAY="${DISPLAY:-:0}"
export WAYLAND_DISPLAY="${WAYLAND_DISPLAY:-wayland-0}"
export XDG_RUNTIME_DIR="${XDG_RUNTIME_DIR:-/mnt/wslg/runtime-dir}"
SH

conda deactivate
conda activate lerobot_mujoco

    先安装 MuJoCo 和 LeRobot：

    pip install mujoco
pip install "lerobot[aloha,pusht]"

    LeRobot 0.4.4 要求 torch<2.11，而你的 Windows 驱动 566.36 / CUDA 12.7 不适合 cu128/cu130，所以最后固定成当前驱动可用的最高兼容组合：

    pip install --timeout 120 --retries 10 \
  torch==2.10.0+cu126 \
  torchvision==0.25.0+cu126 \
  torchaudio==2.10.0+cu126 \
  --index-url https://download.pytorch.org/whl/cu126

    这里不要用 torch 2.11.0+cu126：它本身能用 CUDA，但不满足 LeRobot 0.4.4 的 torch<2.11 约束。

    3.验证 MuJoCo GUI

    先用一个最小方块测试 MuJoCo viewer：

    python - <<'PY'
import time
import mujoco
import mujoco.viewer

xml = """
<mujoco>
  <worldbody>
    <light pos="0 0 3"/>
    <body pos="0 0 0.2">
      <joint type="free"/>
      <geom type="box" size="0.1 0.1 0.1" rgba="0.2 0.6 1 1"/>
    </body>
    <geom type="plane" size="1 1 0.01" rgba="0.8 0.8 0.8 1"/>
  </worldbody>
</mujoco>
"""

model = mujoco.MjModel.from_xml_string(xml)
data = mujoco.MjData(model)

with mujoco.viewer.launch_passive(model, data) as viewer:
    start = time.time()
    while viewer.is_running() and time.time() - start < 10:
        mujoco.mj_step(model, data)
        viewer.sync()
PY

    如果能弹出窗口并看到方块，说明 MuJoCo GUI 路线可用。

    如果 GUI 不弹窗，先跑 headless：

    MUJOCO_GL=osmesa python - <<'PY'
import mujoco

xml = "<mujoco><worldbody><body><geom type='box' size='0.1 0.1 0.1'/></body></worldbody></mujoco>"
model = mujoco.MjModel.from_xml_string(xml)
data = mujoco.MjData(model)
for _ in range(100):
    mujoco.mj_step(model, data)
print("mujoco headless ok")
PY

    先保证 headless 能跑，再解决 GUI。

    5.先跑 LeRobot 自带数据训练

    真正采集机械臂数据前，先验证训练命令能跑。用 Hugging Face 上的公开数据集做最小训练：

    lerobot-train \
  --dataset.repo_id=lerobot/pusht \
  --policy.type=act \
  --output_dir=outputs/train/pusht_act_cuda_test \
  --policy.device=cuda \
  --steps=100 \
  --batch_size=8 \
  --wandb.enable=false

    这一步只验证：

    数据能下载
LeRobot Dataset 能读取
ACT policy 能创建
CUDA 能训练
checkpoint 能保存

    如果 100 steps 能跑，再考虑加大步数：

    lerobot-train \
  --dataset.repo_id=lerobot/pusht \
  --policy.type=act \
  --output_dir=outputs/train/pusht_act_cuda \
  --policy.device=cuda \
  --steps=1000 \
  --batch_size=8 \
  --wandb.enable=false

    6.看机械臂模型的路线

    MuJoCo 里要看到机械臂，本质上需要一个 MJCF/XML 模型。

    优先级：

    1. LeRobot 已支持的 MuJoCo / ALOHA / PushT 环境
2. 已有 MJCF 机械臂模型
3. URDF -> MJCF 转换

    如果你只是想先看机械臂，不要一开始导入复杂 URDF。先找 LeRobot 或 MuJoCo Menagerie 里已有模型：

    mkdir -p ~/github_project
cd ~/github_project
git clone https://github.com/google-deepmind/mujoco_menagerie.git

    然后用 Python 加载对应 XML：

    python - <<'PY'
from pathlib import Path
import time
import mujoco
import mujoco.viewer

xml_path = Path.home() / "github_project/mujoco_menagerie/universal_robots_ur5e/scene.xml"
model = mujoco.MjModel.from_xml_path(str(xml_path))
data = mujoco.MjData(model)

with mujoco.viewer.launch_passive(model, data) as viewer:
    start = time.time()
    while viewer.is_running() and time.time() - start < 20:
        mujoco.mj_step(model, data)
        viewer.sync()
PY

    如果这个模型路径不存在，先列出 menagerie 里有什么：

    find ~/github_project/mujoco_menagerie -maxdepth 2 -name "scene.xml" | head -30

    7.后续接 LeRobot 数据

    LeRobot 训练关心的不是仿真器名字，而是数据格式：

    observation.image
observation.state
action
episode_index
frame_index
timestamp

    MuJoCo 环境里采集到的数据，最后也要整理成 LeRobot Dataset。流程是：

    MuJoCo 环境
-> 遥操作或脚本策略产生 action
-> 记录 observation/action
-> 转成 LeRobot Dataset
-> lerobot-train 训练 ACT / Diffusion Policy

    如果只是学习，先不要自己写完整采集器。先用公开数据集训练，确认 LeRobot 训练链路，然后再做自己的 MuJoCo 机械臂采集。

    8.常见问题

    8.1 MuJoCo GUI 不打开

    先补 WSLg 环境变量。如果想让 OpenGL 走 WSLg 的 D3D12 后端，可以加 GALLIUM_DRIVER=d3d12：

    export DISPLAY=:0
export WAYLAND_DISPLAY=wayland-0
export XDG_RUNTIME_DIR=/mnt/wslg/runtime-dir
export GALLIUM_DRIVER=d3d12

    检查 OpenGL 是否走到 3060：

    glxinfo -B | grep -E "OpenGL renderer|Accelerated"

    期望类似：

    Accelerated: yes
OpenGL renderer string: D3D12 (NVIDIA GeForce RTX 3060 Laptop GPU)

    注意：这只说明普通 OpenGL/GLFW 可用，不保证 mujoco.viewer 稳定。实测当前 WSLg + d3d12 下，普通 GLFW 窗口可以连续刷新，但 mujoco.viewer.launch_passive() 仍可能运行一小会后报：

    GLXBadDrawable
X_GLXSwapBuffers
Segmentation fault

    这个问题在 MuJoCo 的 Python viewer / GLFW / WSLg GLX 组合上，不是 Torch CUDA 问题。训练和批量仿真先用 headless：

    MUJOCO_GL=egl python your_script.py
MUJOCO_GL=osmesa python your_script.py

    如果只是想确认画面，可以先做离屏渲染保存图片；如果必须实时 GUI，优先考虑 Windows 原生 Python/MuJoCo 或实体 Ubuntu 桌面。

    8.2 LeRobot 下载 Hugging Face 数据慢

    export HF_HOME=~/huggingface
export HF_ENDPOINT=https://hf-mirror.com

    如果镜像不稳定，就去掉 HF_ENDPOINT。

    8.3 训练还是很慢

    RTX 3060 Laptop 只有 6GB 显存，能跑不等于适合大 batch。先从小 batch 开始：

    --batch_size=4

    如果仍然 OOM 或太慢，再把训练放到云端，本地只用 MuJoCo 看仿真和调数据格式。

    8.4 pip 又把 Torch 换掉了

    安装 LeRobot 后最后再执行一次：

    pip install --timeout 120 --retries 10 \
  torch==2.10.0+cu126 \
  torchvision==0.25.0+cu126 \
  torchaudio==2.10.0+cu126 \
  --index-url https://download.pytorch.org/whl/cu126

    然后验证：

    python - <<'PY'
import torch
print(torch.__version__)
print(torch.version.cuda)
print(torch.cuda.is_available())
print(torch.cuda.get_device_name(0))
PY

    8.5 什么时候再用 Isaac Sim

    等你需要这些能力时再回 Isaac Sim：

    RTX 光照和复杂传感器
USD 场景
Isaac Lab 强化学习任务
更接近真实机器人系统的高保真仿真

    当前不更新驱动，就不要把 Isaac Sim 放在主线。

    9.最终验收标准

    跑通这篇教程后，至少要做到：

    1. MuJoCo 最小 viewer 能打开，或 headless 能 step 100 次
2. lerobot-train --help 能运行
3. torch.cuda.is_available() 为 True，设备名是 RTX 3060 Laptop GPU
4. lerobot/pusht 能用 --policy.device=cuda 训练 100 steps
5. outputs/train/ 下能看到 checkpoint
6. 能加载一个 MuJoCo Menagerie 机械臂模型并看到窗口

    最小闭环：

    WSL2 Ubuntu 24.04
-> torch 2.10.0+cu126 可用
-> MuJoCo GUI/headless 可用
-> LeRobot 可用
-> 公开数据集可用 CUDA 训练
-> 再接自己的 MuJoCo 机械臂数据
