    LeRobot SO-101机械臂

    LeRobot 代码：https://github.com/huggingface/lerobot

    官方文档地址：https://huggingface.co/docs/lerobot/installation

    全套流程

    1.安装环境

    conda create -y -n lerobot python=3.12
conda activate lerobot

conda install evdev ffmpeg -c conda-forge
pip install -e ".[training,dataset_viz,pusht,diffusion]"

    说明： training 用来训练，dataset_viz 用来看数据，pusht 用来无实物跑仿真环境，diffusion 用来看 Diffusion Policy。先别装 all，太大，问题也多。

    2.验证安装

    python -c "import lerobot; print(lerobot.__file__)"
lerobot-info --help
lerobot-train --help
lerobot-eval --help
lerobot-dataset-viz --help

    如果 CLI 能显示 help，说明入口装好了。

    3.无实物跑通最小全流程

    目标不是训练出好模型，而是先跑通完整链路：

    公开数据集 -> 训练 ACT 10 步 -> 保存 checkpoint -> 加载 checkpoint 评估

    3.1 进入项目和环境

    conda activate lerobot
cd ~/github_project/lerobot

    如果宿主机显卡驱动不想改，先全部使用 CPU：

    所有训练和评估命令都加：--policy.device=cpu

    3.2 检查公开数据集

    python - <<'PY'
from lerobot.datasets.lerobot_dataset import LeRobotDataset

ds = LeRobotDataset("lerobot/pusht")
print("frames:", len(ds))
print("episodes:", ds.num_episodes)
print("features:")
for k, v in ds.features.items():
    print(" ", k, v)

sample = ds[0]
print("\none sample:")
for k, v in sample.items():
    print(" ", k, type(v), getattr(v, "shape", None))

    这份输出说明 lerobot/pusht 数据集已经可以正常读取。

    frames: 25650
episodes: 206

    含义：

    frames    总帧数，也就是所有轨迹加起来的时间步数量
episodes  示教轨迹数量，可以理解为 206 次完整任务尝试

    训练最核心的是三个字段：

    observation.image   图像输入，模型看到的画面
observation.state   状态输入，当前环境/控制点状态
action              示教动作，也就是模型要学习预测的答案

    features 里的 shape 是数据集声明的原始格式：

    observation.image: (96, 96, 3)  # height, width, channel
observation.state: (2,)
action: (2,)

    one sample 里打印的是 PyTorch 实际取出的一帧：

    observation.image: torch.Size([3, 96, 96])
observation.state: torch.Size([2])
action: torch.Size([2])

    图像 shape 从 (96, 96, 3) 变成 [3, 96, 96] 是正常的。很多 PyTorch 模型使用：

    channel, height, width

    而不是图片文件常见的：

    height, width, channel

    observation.state 和 action 都是二维，说明这个任务的控制量很小，可以先理解为平面上的两个控制方向。它不是 SO-101 机械臂的 6 个关节数据。

    这些字段是辅助信息：

    episode_index  第几条轨迹
frame_index    当前轨迹里的第几帧
timestamp      时间戳
index          全数据集里的全局索引
task_index     任务编号
task           任务文本

    这些字段先跳过：

    next.reward
next.done
next.success

    它们更偏仿真/强化学习评估，用来描述下一步奖励、是否结束、是否成功。模仿学习入门阶段先只看：

    observation -> action

    训练目标可以先理解成：

    policy(observation.image, observation.state) = action

    3.3 数据集输出含义

    lerobot/pusht 是一个推块任务数据集。常见输出：

    frames: 25650
episodes: 206

    含义：

    frames    总帧数
episodes  示教轨迹数量

    核心字段：

    observation.image  RGB 图像，通常是 torch.Size([3, 96, 96])
observation.state  当前状态，通常是二维状态
action             下一步动作，通常是二维控制量

    辅助字段：

    episode_index  第几条轨迹
frame_index    当前轨迹里的第几帧
timestamp      时间戳
next.reward    下一步奖励
next.done      是否结束
next.success   是否成功

    先跳过 next.* 字段，模仿学习入门阶段只盯住：

    observation -> action

    3.4 跑一个极小训练

    CPU 训练 10 步：

    lerobot-train \
  --policy.type=act \
  --dataset.repo_id=lerobot/pusht \
  --output_dir=outputs/train/act_pusht_debug \
  --job_name=act_pusht_debug \
  --policy.device=cpu \
  --policy.push_to_hub=false \
  --wandb.enable=false \
  --steps=10 \
  --batch_size=2 \
  --num_workers=0 \
  --log_freq=1 \
  --save_freq=10

    如果太慢，先压到 2 步：

    lerobot-train \
  --policy.type=act \
  --dataset.repo_id=lerobot/pusht \
  --output_dir=outputs/train/act_pusht_debug \
  --job_name=act_pusht_debug \
  --policy.device=cpu \
  --wandb.enable=false \
  --steps=2 \
  --batch_size=2 \
  --num_workers=0 \
  --log_freq=1 \
  --save_freq=2

    这一步重点观察：

    loss 是否打印
outputs/train/act_pusht_debug 是否生成 checkpoint

    3.5 查看训练产物

    find outputs/train/act_pusht_debug -maxdepth 5 -type f | sort | head -80
find outputs/train/act_pusht_debug -maxdepth 5 -type d | sort

    训练产物里通常包含：

    模型权重
模型配置
processor 配置
checkpoint 目录

    3.6 加载 checkpoint 做评估

    先尝试：

    lerobot-eval \
  --policy.path=outputs/train/act_pusht_debug/checkpoints/last/pretrained_model \
  --env.type=pusht \
  --policy.device=cpu \
  --eval.n_episodes=1 \
  --eval.batch_size=1

    如果路径不存在，先查实际 checkpoint 目录：

    find outputs/train/act_pusht_debug -maxdepth 5 -type d | sort

    把包含模型文件的目录传给：

    --policy.path=...

    3.7 本地数据缓存位置

    lerobot/pusht 会缓存到 Hugging Face cache。当前机器上查到的位置：

    ~/.cache/huggingface/lerobot/hub/datasets--lerobot--pusht

    绝对路径：

    /home/yzh/.cache/huggingface/lerobot/hub/datasets--lerobot--pusht

    查看文件：

    ls -lah ~/.cache/huggingface/lerobot/hub/datasets--lerobot--pusht
find ~/.cache/huggingface/lerobot/hub/datasets--lerobot--pusht -maxdepth 3 -type f | head -80

    3.8 跑通后的理解闭环

    LeRobotDataset("lerobot/pusht")
  ↓
DataLoader 取 batch
  ↓
ACTPolicy.forward(batch)
  ↓
计算 loss
  ↓
optimizer 更新参数
  ↓
保存 checkpoint
  ↓
lerobot-eval 加载 checkpoint
  ↓
policy.select_action(obs)
  ↓
仿真环境执行 action

    4.AutoDL 算力服务器训练

    本节基于这个 AutoDL 镜像：

    NVIDIA/cuda-samples/CUDA13.0-Torch2.7.0-Python3.11

    注意关键点：

    镜像自带 Python 3.11
当前 LeRobot 0.5.2 要求 Python >= 3.12
所以不能直接用镜像 base 环境，需要新建 python=3.12 的 conda 环境

    AutoDL 上训练的目的：

    用 GPU 把 steps 拉高，训练出能看出效果的 ACT PushT 模型

    4.1 进入 AutoDL 后先做基础检查

    nvidia-smi
python --version
python - <<'PY'
import torch
print("torch:", torch.__version__)
print("cuda:", torch.cuda.is_available())
if torch.cuda.is_available():
    print("gpu:", torch.cuda.get_device_name(0))
PY

    这里看到 Python 3.11 是正常的。后面脚本会创建 python=3.12 环境。

    4.2 一键安装和训练脚本

    在 AutoDL 终端中新建脚本：

    nano autodl_lerobot_pusht.sh

    粘贴下面内容：

    #!/usr/bin/env bash
set -e

PROJECT_DIR="${PROJECT_DIR:-/root/github_project/lerobot}"
CONDA_ENV="${CONDA_ENV:-lerobot}"
PYTHON_VERSION="${PYTHON_VERSION:-3.12}"
STEPS="${STEPS:-100000}"
BATCH_SIZE="${BATCH_SIZE:-8}"
SAVE_FREQ="${SAVE_FREQ:-10000}"
LOG_FREQ="${LOG_FREQ:-100}"
OUTPUT_DIR="${OUTPUT_DIR:-outputs/train/act_pusht_100k}"
JOB_NAME="${JOB_NAME:-act_pusht_100k}"

echo "==> 当前镜像基础信息"
nvidia-smi || true
python --version || true

echo "==> 检查 conda"
if ! command -v conda >/dev/null 2>&1; then
  echo "没有找到 conda。这个流程需要 AutoDL 镜像内置 conda。"
  exit 1
fi

echo "==> 安装系统依赖"
apt-get update
apt-get install -y git git-lfs ffmpeg libgl1 libglib2.0-0
git lfs install

echo "==> 获取 LeRobot 项目"
mkdir -p "$(dirname "$PROJECT_DIR")"
if [ ! -d "$PROJECT_DIR/.git" ]; then
  git clone https://github.com/huggingface/lerobot.git "$PROJECT_DIR"
fi

cd "$PROJECT_DIR"

echo "==> 创建/激活 Python 3.12 conda 环境"
source "$(conda info --base)/etc/profile.d/conda.sh"
if ! conda env list | awk '{print $1}' | grep -qx "$CONDA_ENV"; then
  conda create -y -n "$CONDA_ENV" "python=$PYTHON_VERSION"
fi
conda activate "$CONDA_ENV"

echo "==> 当前训练环境"
which python
python --version

echo "==> 升级 pip 基础工具"
python -m pip install -U pip setuptools wheel

echo "==> 安装 LeRobot 训练和 PushT 依赖"
python -m pip install -e ".[training,pusht]"

echo "==> 检查 PyTorch 和 CUDA"
python - <<'PY'
import torch
print("torch:", torch.__version__)
print("torch cuda version:", torch.version.cuda)
print("cuda available:", torch.cuda.is_available())
if torch.cuda.is_available():
    print("gpu:", torch.cuda.get_device_name(0))
else:
    raise SystemExit("CUDA 不可用：通常是新 conda 环境里的 torch 没装到 CUDA 版本，或镜像/驱动不匹配")
PY

echo "==> 检查 LeRobot CLI"
lerobot-info --help | head -40

echo "==> 开始训练"
lerobot-train \
  --policy.type=act \
  --dataset.repo_id=lerobot/pusht \
  --output_dir="$OUTPUT_DIR" \
  --job_name="$JOB_NAME" \
  --policy.device=cuda \
  --policy.push_to_hub=false \
  --wandb.enable=false \
  --steps="$STEPS" \
  --batch_size="$BATCH_SIZE" \
  --num_workers=4 \
  --log_freq="$LOG_FREQ" \
  --save_freq="$SAVE_FREQ"

echo "==> 训练完成，开始评估"
lerobot-eval \
  --policy.path="$OUTPUT_DIR/checkpoints/last/pretrained_model" \
  --env.type=pusht \
  --policy.device=cuda \
  --eval.n_episodes=10 \
  --eval.batch_size=10

echo "==> 完成"
echo "模型目录: $PROJECT_DIR/$OUTPUT_DIR/checkpoints/last/pretrained_model"
echo "评估输出: $PROJECT_DIR/outputs/eval"

    执行：

    chmod +x autodl_lerobot_pusht.sh
./autodl_lerobot_pusht.sh

    4.3 如果新环境里 CUDA 不可用

    如果脚本报：

    cuda available: False

    先进入环境：

    source "$(conda info --base)/etc/profile.d/conda.sh"
conda activate lerobot
cd /root/github_project/lerobot

    重新安装 CUDA 版 PyTorch。这个镜像名是 CUDA13.0，但 PyTorch wheel 通常按 cu128、cu130 这类标签发布。优先试：

    python -m pip install -U torch torchvision --index-url https://download.pytorch.org/whl/cu130

    如果 cu130 找不到包，再试：

    python -m pip install -U torch torchvision --index-url https://download.pytorch.org/whl/cu128

    验证：

    python - <<'PY'
import torch
print(torch.__version__)
print(torch.version.cuda)
print(torch.cuda.is_available())
if torch.cuda.is_available():
    print(torch.cuda.get_device_name(0))
PY

    验证通过后重新运行：

    ./autodl_lerobot_pusht.sh

    4.4 先跑一个小版本确认环境

    第一次不要直接跑 100000 step，先跑 1000 step 验证安装、下载数据集、训练、评估全流程：

    STEPS=1000 \
BATCH_SIZE=8 \
SAVE_FREQ=1000 \
OUTPUT_DIR=outputs/train/act_pusht_1k \
JOB_NAME=act_pusht_1k \
./autodl_lerobot_pusht.sh

    确认没问题后再正式跑：

    STEPS=100000 \
BATCH_SIZE=8 \
SAVE_FREQ=10000 \
OUTPUT_DIR=outputs/train/act_pusht_100k \
JOB_NAME=act_pusht_100k \
./autodl_lerobot_pusht.sh

    4.5 如果 Hugging Face 下载慢

    AutoDL 国内网络访问 Hugging Face 可能不稳定。可以先设置镜像：

    export HF_ENDPOINT=https://hf-mirror.com

    然后再执行脚本：

    ./autodl_lerobot_pusht.sh

    如果想长期生效：

    echo 'export HF_ENDPOINT=https://hf-mirror.com' >> ~/.bashrc
source ~/.bashrc

    4.6 断点继续训练

    如果训练中断，先找最新 checkpoint：

    cd /root/github_project/lerobot
ls -lah outputs/train/act_pusht_100k/checkpoints

    查看当前版本是否支持 resume：

    lerobot-train --help | grep -i resume

    如果支持，使用类似命令：

    lerobot-train \
  --config_path=outputs/train/act_pusht_100k/checkpoints/last/pretrained_model/train_config.json \
  --resume=true

    如果不支持，就从已有 checkpoint 做评估，或者重新跑一个更长的训练。

    4.7 训练完成后重点看什么

    评估输出里先看这几个字段：

    pc_success       成功率，越高越好
avg_sum_reward   单局累计奖励，越高越好
video_paths      评估视频路径，最直观

    视频通常在：

    outputs/eval/日期/时间_pusht_act/videos/pusht_0/

    查看：

    find outputs/eval -name "*.mp4" | sort | tail -20

    4.8 把训练结果下载回本地

    最应该下载的是：

    outputs/train/act_pusht_100k/checkpoints/last/pretrained_model
outputs/eval

    在 AutoDL 上先打包：

    cd /root/github_project/lerobot
tar -czf act_pusht_100k_result.tar.gz \
  outputs/train/act_pusht_100k/checkpoints/last/pretrained_model \
  outputs/eval

    然后用 AutoDL 网页文件管理器下载：

    act_pusht_100k_result.tar.gz

    4.9 推荐训练参数

    学习闭环: steps=1000, batch_size=8
看初步效果: steps=10000, batch_size=8
认真训练: steps=100000, batch_size=8

    先不要调复杂参数。当前阶段只观察：

    steps 增加后，loss 是否下降
评估视频是否越来越像正确推 T
pc_success 是否从 0 开始上涨
