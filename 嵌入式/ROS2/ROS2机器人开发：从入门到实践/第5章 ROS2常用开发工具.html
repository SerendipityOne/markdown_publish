    ROS2常用开发工具

    让ROS2成为机器人开发利器的，不仅仅是前面介绍过的通信机制，还有各种强大易用的工具。前面我们用到过的rqt就是ROS2常用的可视化工具之一，本章将着重介绍ROS2机器人开发过程中的常用工具。

    在机器人的开发过程中，坐标变换非常重要且不好处理，ROS2就基于话题通信设计了一套库和工具，用于管理机器人坐标变换。

    坐标变换工具介绍

    从代码清单5-8的结果可以看出，tf2msgs/msg/TFMessage主要由geometry_msgs/TransformStamped的数组构成。

    每个TransformStamped包含以下字段：

    1. Header部分
      • header: 标准消息头
        • stamp: 时间戳
          • sec: 秒部分（int32）
          • nanosec: 纳秒部分（uint32）
        • frame_id: 父坐标系名称（string）
    2. 坐标系信息
      • child_frame_id: 子坐标系名称（string）
    3. Transform变换信息
      • transform: 具体的变换数据
        • translation: 平移部分（Vector3）
          • x: x方向平移量（float64）
          • y: y方向平移量（float64）
          • z: z方向平移量（float64）
        • rotation: 旋转部分（Quaternion）
          • x: 四元数x分量（float64，默认0）
          • y: 四元数y分量（float64，默认0）
          • z: 四元数z分量（float64，默认0）
          • w: 四元数w分量（float64，默认1）

    Python中的手眼坐标变换

    通过Python发布静态TF

    ​ 图中机械臂底座和相机一般是固定起来的，它们之间的坐标关系固定不变，可以采用静态的TF进行发布。接着我们用Python编写节点来进行静态的TF发布。

    ​ 因为TF发布时，旋转表示要使用四元数，所以要使用代码将欧拉角转换成四元数形式， ROS2中tf_transformations库提供这一功能。

    sudo apt install ros-$ROS_DISTRO-tf-transformations

    在chapt5/chapt5_ws/src下运行

    ros2 pkg create demo_python_tf --build-type ament_python --dependencies rclpy geomerty_msgs tf_ros tf_transformations --license Apache-2.0

    上面的命令创建了demo_python_tf功能包。依赖tf_ros用于发布广播，geometry_msgs是发布坐标变换所需要的消息接口，tf_transformations用于提供姿态转换相关函数。创建完成后，在chapts5_ws/src/demo_python_tf/demo_python_tf下新建static_tf_broadcaster.py

    import rclpy
from rclpy.node import Node
from tf2_ros import StaticTransformBroadcaster
from geometry_msgs.msg import TransformStamped
from tf_transformations import quaternion_from_euler
import math


class StaticTfBroadcaster(Node):
    """
    静态坐标变换广播器节点类

    该类继承自ROS2的Node类，用于发布静态坐标变换信息。
    它创建一个从base_link到camera_link的静态坐标变换。
    """

    def __init__(self):
        """
        初始化静态坐标变换广播器节点

        创建StaticTransformBroadcaster实例并调用发布静态坐标变换的方法。
        """
        super().__init__("static_tf_broadcaster")
        self.static_broadcaster = StaticTransformBroadcaster(self)
        self.publish_static_tf()

    def publish_static_tf(self):
        """
        发布静态坐标变换

        创建并配置一个TransformStamped消息，设置从base_link到camera_link的变换关系，
        包括平移和旋转信息，并通过静态坐标变换广播器发布。
        """
        transform = TransformStamped()
        transform.header.stamp = self.get_clock().now().to_msg()
        transform.header.frame_id = "base_link"
        transform.child_frame_id = "camera_link"
        transform.transform.translation.x = 0.5
        transform.transform.translation.y = 0.3
        transform.transform.translation.z = 0.6
        # 欧拉角转四元组
        q = quaternion_from_euler(math.radians(180), 0.0, 0.0)
        transform.transform.rotation.x = q[0]
        transform.transform.rotation.y = q[1]
        transform.transform.rotation.z = q[2]
        transform.transform.rotation.w = q[3]

        # 发布静态坐标变换
        self.static_broadcaster.sendTransform(transform)
        self.get_logger().info(f"发布静态tf：{transform}")


def main(args=None):
    """
    主函数

    初始化ROS2客户端库，创建静态坐标变换广播器节点，
    运行节点并处理程序退出时的清理工作。

    Args:
        args: 命令行参数，默认为None
    """
    rclpy.init(args=args)
    static_tf_broadcaster = StaticTfBroadcaster()
    rclpy.spin(static_tf_broadcaster)
    static_tf_broadcaster.destroy_node()
    rclpy.shutdown()
