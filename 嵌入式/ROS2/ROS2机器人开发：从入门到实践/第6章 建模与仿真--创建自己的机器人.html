    建模与仿真--创建自己的机器人

    在实际开发中，将算法和程序部署到真实的机器人之前，往往会采用仿真的机器人进行验证。毕竟不用担心仿真机器人没电或者磕碰到。在没有实体机器人时，仿真依然是一个不错的选择。但仿真前需要先对我们要仿真的机器人进行建模。

    使用URDF创建机器人

    仿真的第一步就是要完成对机器人的建模，虽然不同的仿真平台有不同的建模语言，但它们几乎都支持URDF(Unified Robot Description Format,通用的机器人描述文件格式)。本节我们就利用URDF完成一个移动机器人模型。

    帮机器人创建一个身体

    URDF使用XML（Extensible Markup Language,可扩展标记语言)来描述机器人的几何结构、传感器和执行器等信息。

    在chapt6/chapt6_ws/src下创建功能包

    $ ros2 pkg create fishbot_description --build-type ament_cmake --license Apache-2.0

    创建urdf文件夹并在其目录下创建first_robot.urdf文件

    <?xml version="1.0"?>
<robot name="fisrt_robot">
    <!-- 机器人身体部分 -->
    <link name="base_link">
        <visual>
            <!-- 根据自己几何中心的偏移与旋转量 -->
            <origin rpy="0 0 0" xyz="0 0 0"/>
            <!-- 几何形状 -->
            <geometry>
                <!-- 圆柱体，半径0.1m，高度0.12m -->
                <cylinder radius="0.1" length="0.12"/>
            </geometry>
            <!-- 材质颜色 -->
            <material name="base_material">
                <!-- rgba: 颜色值，alpha透明度 -->
                <color rgba="1 1 1 0.5"/>
            </material>
        </visual>
    </link>

    <!-- IMU 传感器 -->
    <link name="imu_link">
        <visual>
            <!-- 根据自己几何中心的偏移与旋转量 -->
            <origin rpy="0 0 0" xyz="0 0 0"/>
            <!-- 几何形状 -->
            <geometry>
                <box size="0.02 0.02 0.02"/>
            </geometry>
            <!-- 材质颜色 -->
            <material name="imu_material">
                <!-- rgba: 颜色值，alpha透明度 -->
                <color rgba="0 0 0 0.5"/>
            </material>
        </visual>
    </link>

    <!-- 机器人关节 -->
    <joint name="imu_joint" type="fixed">
        <parent link="base_link"/>
        <child link="imu_link"/>
        <!-- 子部件相对于父部件的平移和旋转 -->
        <origin xyz="0.0 0.0 0.03" rpy="0.0 0.0 0.0"/>
    </joint>

</robot>

    仅仅看到URDF的结构还不够，我们如果能直观地看到机器人的样子就更好了，接下来我们尝试在RViz中将机器人显示出来。

    在RViz中显示机器人

    在RViz中，可以直接使用RobotModel模块从文件加载URDF并显示。

    $ sudo apt install ros-$ROS_DISTRO-robot-state-publisher ros-$ROS_DISTRO-joint-state-publisher

    为了方便运行，我们使用launch文件组织节点，在fishbot_description目录下新建launch目录，接着创建display_robot.launch..py,然后编写代码清单6-6中的代码。

    import os
from launch import LaunchDescription
from launch_ros.actions import Node
from ament_index_python.packages import get_package_share_directory


def generate_launch_description():
    # 获取URDF文件路径
    urdf_path = os.path.join(
        get_package_share_directory("fishbot_description"), "urdf", "first_robot.urdf"
    )

    # 读取URDF文件内容
    with open(urdf_path, "r") as infp:
        robot_desc = infp.read()

    # 创建robot_state_publisher节点
    robot_state_publisher_node = Node(
        package="robot_state_publisher",
        executable="robot_state_publisher",
        name="robot_state_publisher",
        parameters=[{"robot_description": robot_desc}],
    )

    # 创建joint_state_publisher节点
    joint_state_publisher_node = Node(
        package="joint_state_publisher",
        executable="joint_state_publisher",
        name="joint_state_publisher",
    )

    # 创建RViz2节点
    rviz_node = Node(
        package="rviz2",
        executable="rviz2",
        name="rviz2",
        arguments=[
            "-d",
            os.path.join(
                get_package_share_directory("fishbot_description"),
                "config",
                "rviz",
                "display_model.rviz",
            ),
        ],
        output="screen",
    )

    # 返回launch描述
    return LaunchDescription(
        [robot_state_publisher_node, joint_state_publisher_node, rviz_node]
    )

    urdf_path获取fishbot_description包的共享目录，然后构建URDF文件的完整路径。打开并读取URDF文件内容，存储在robot_desc变量中，供后续使用。创建robot_state_publisher节点，这个节点负责：将URDF机器人模型发布到/robot_description话题，根据关节状态消息计算并发布机器人各部分的TF变换

    • /robot_description 是ROS2中的一个关键话题(Topic)，用于发布机器人的URDF(Unified Robot Description Format)描述信息。它是一个字符串类型的消息，包含了机器人的完整结构描述，包括链接(links)、关节(joints)、传感器等所有组件的几何和运动学信息。

    rviz配置文件请看：display_model.rviz

    使用Xacro简化URDF

    Xacro(XML Macro)是基于XML的宏语言，用于简化URDF文件的创建和维护。使用它可以将部件等定义为宏，在需要的时候调用即可。

    src/fishbot_description/urdf/first_robot.urdf.xacro

    <?xml version="1.0"?>
<robot xmlns:xacro="http://www.ros.org/wiki/xacro" name="fisrt_robot">
    <xacro:macro name="base_link" params="length radius">
        <!-- 机器人身体部分 -->
        <link name="base_link">
            <visual>
                <!-- 根据自己几何中心的偏移与旋转量 -->
                <origin rpy="0 0 0" xyz="0 0 0"/>
                <!-- 几何形状 -->
                <geometry>
                    <!-- 圆柱体，半径0.1m，高度0.12m -->
                    <cylinder radius="${radius}" length="${length}"/>
                </geometry>
                <!-- 材质颜色 -->
                <material name="base_material">
                    <!-- rgba: 颜色值，alpha透明度 -->
                    <color rgba="1 1 1 0.5"/>
                </material>
            </visual>
        </link>
    </xacro:macro>


    <xacro:macro name="imu_link" params="imu_name xyz">
        <!-- IMU 传感器 -->
        <link name="${imu_name}_link">
            <visual>
                <!-- 根据自己几何中心的偏移与旋转量 -->
                <origin rpy="0 0 0" xyz="0 0 0"/>
                <!-- 几何形状 -->
                <geometry>
                    <box size="0.02 0.02 0.02"/>
                </geometry>
                <!-- 材质颜色 -->
                <material name="imu_material">
                    <!-- rgba: 颜色值，alpha透明度 -->
                    <color rgba="0 0 0 0.5"/>
                </material>
            </visual>
        </link>

        <!-- 机器人关节 -->
        <joint name="${imu_name}_joint" type="fixed">
            <parent link="base_link"/>
            <child link="${imu_name}_link"/>
            <!-- 子部件相对于父部件的平移和旋转 -->
            <origin xyz="${xyz}" rpy="0.0 0.0 0.0"/>
        </joint>
    </xacro:macro>

    <xacro:base_link length="0.12" radius="0.1"/>
    <xacro:imu_link imu_name="imu_up" xyz="0 0 0.03"/>
    <xacro:imu_link imu_name="imu_down" xyz="0 0 -0.03"/>

</robot>

    贴合地面，添加虚拟部件

    在RVz中水平观察机器人，你会发现机器人的轮子陷入到了地面之下，通过添加虚拟关节可以解决这一问题

    <?xml version="1.0"?>
<robot name="fishbot_base" xmlns:xacro="http://www.ros.org/wiki/xacro">
  <xacro:macro name="fishbot_base" params="radius height *origin">
    <link name="base_footprint"/>

    <link name="base_link">
      ...
    </link>

    <joint name="base_joint" type="fixed">
      <origin xyz="0.0 0.0 ${height/2+0.032-0.001}" rpy="0.0 0.0 0.0"/>
      <parent link="base_footprint"/>
      <child link="base_link"/>
    </joint>
  </xacro:macro>
</robot>

    为机器人部件添加质量与惯性

    <?xml version="1.0"?>
<robot xmlns:xacro="http://ros.org/wiki/xacro">
  <xacro:macro name="box_inertia" params="m w h d">
    <inertial>
      <mass value="${m}" />
      <inertia ixx="${(m/12) * (h*h + d*d)}" ixy="0.0" ixz="0.0" iyy="${(m/12) * (w*w + d*d)}" iyz="0.0" izz="${(m/12) * (w*w + h*h)}" />
    </inertial>
  </xacro:macro>

  <xacro:macro name="cylinder_inertia" params="m r h">
    <inertial>
      <mass value="${m}" />
      <inertia ixx="${(m/12) * (3*r*r + h*h)}" ixy="0" ixz="0" iyy="${(m/12) * (3*r*r + h*h)}" iyz="0" izz="${(m/2) * (r*r)}" />
    </inertial>
  </xacro:macro>

  <xacro:macro name="sphere_inertia" params="m r">
    <inertial>
      <mass value="${m}" />
      <inertia ixx="${(2/5) * m * (r*r)}" ixy="0.0" ixz="0.0" iyy="${(2/5) * m * (r*r)}" iyz="0.0" izz="${(2/5) * m * (r*r)}" />
    </inertial>
  </xacro:macro>

</robot>


    <?xml version="1.0"?>
<robot name="fishbot_base" xmlns:xacro="http://www.ros.org/wiki/xacro">
    <xacro:include filename="$(find fishbot_description)/urdf/fishbot/common_inertia.xacro"/>

    <xacro:macro name="fishbot_base" params="radius height *origin">
        <link name="base_footprint"/>

        <link name="base_link">
            ...

            <!-- 惯性 参数 -->
            <xacro:cylinder_inertia m="1" r="${radius}" h="${height}"/>
        </link>

        ...
    </xacro:macro>
</robot>

    在Gazebo中加载机器人模型

    Gazebo使用的是sdf格式，而我们的机器人建模使用的是URDF,所以要想在Gazebo中显示机器人模型，就需要将URDF转换成sdf。

    $ sudo apt install ros-$ROS_DISTRO-gazebo-ros-pkgs

    src/fishbot_description/launch/gazebo_sim.launch.py

    import os
from launch import LaunchDescription
from launch.actions import DeclareLaunchArgument, IncludeLaunchDescription
from launch.substitutions import LaunchConfiguration
from launch_ros.actions import Node
from ament_index_python.packages import get_package_share_directory
from launch.substitutions import Command
from launch.launch_description_sources import PythonLaunchDescriptionSource


def generate_launch_description():
  # 声明launch参数
  world_arg = DeclareLaunchArgument(
    "world",
    default_value=os.path.join(
      get_package_share_directory("fishbot_description"),
      "world",
      "custom_room.sdf",
    ),
    description="World file path",
  )

  # 声明URDF文件路径参数
  model_arg = DeclareLaunchArgument(
    "model",
    default_value=os.path.join(
      get_package_share_directory("fishbot_description"),
      "urdf",
      "fishbot",
      "fishbot.urdf.xacro",
    ),
    description="URDF file path",
  )

  # 获取参数配置
  world = LaunchConfiguration("world")
  model = LaunchConfiguration("model")

  # 获取机器人描述
  robot_desc = Command(["xacro ", model])

  # 创建robot_state_publisher节点
  robot_state_publisher_node = Node(
    package="robot_state_publisher",
    executable="robot_state_publisher",
    name="robot_state_publisher",
    parameters=[{"robot_description": robot_desc}],
  )

  # 使用IncludeLaunchDescription包含gazebo.launch.py
  launch_gazebo = IncludeLaunchDescription(
    PythonLaunchDescriptionSource(
      [get_package_share_directory("gazebo_ros"), "/launch", "/gazebo.launch.py"]
    ),
    launch_arguments=[("world", world), ("verbose", "true")],
  )

  # 在Gazebo中生成机器人模型
  spawn_entity_node = Node(
    package="gazebo_ros",
    executable="spawn_entity.py",
    arguments=[
      "-topic",
      "robot_description",
      "-entity",
      "fishbot",
    ],
    output="screen",
  )

  # 返回launch描述
  return LaunchDescription(
    [
      world_arg,
      model_arg,
      launch_gazebo,
      robot_state_publisher_node,
      spawn_entity_node,
    ]
  )

    使用两轮差速插件控制机器人

    src/fishbot_description/urdf/fishbot/plugins/gazebo_control_plugin.xacro

    <?xml version="1.0"?>
<robot xmlns:xacro="http://www.ros.org/wiki/xacro">
  <xacro:macro name="gazebo_control_plugin">
    <gazebo>
      <plugin name='diff_drive' filename='libgazebo_ros_diff_drive.so'>
        <ros>
          <namespace></namespace>
          <remapping>cmd_vel:=cmd_vel</remapping>
          <remapping>odom:=odom</remapping>
        </ros>
        <update_rate>30</update_rate>
        <!-- wheels -->
        <left_joint>left_wheel_joint</left_joint>
        <right_joint>right_wheel_joint</right_joint>
        <!-- kinematics -->
        <wheel_separation>0.2</wheel_separation>
        <wheel_diameter>0.064</wheel_diameter>
        <!-- limits -->
        <max_wheel_torque>20</max_wheel_torque>
        <max_wheel_acceleration>1.0</max_wheel_acceleration>
        <!-- output -->
        <publish_odom>true</publish_odom>
        <publish_odom_tf>true</publish_odom_tf>
        <publish_wheel_tf>true</publish_wheel_tf>

        <odometry_frame>odom</odometry_frame>
        <robot_base_frame>base_footprint</robot_base_frame>
      </plugin>
    </gazebo>
  </xacro:macro>
</robot>

    代码详解

    • <ros>: 配置与 ROS 通信相关的参数。<namespace>: ROS 节点的命名空间，这里为空，表示在全局命名空间下。<remapping>: 话题重映射。将插件的内部输入话题 cmd_vel（速度指令）和输出话题 odom（里程计信息）分别映射到 ROS 的同名话题上。<update_rate>: 插件的更新频率，单位为 Hz。这里表示控制器每秒计算并更新 30 次。<left_joint> 和 <right_joint>: 指定机器人左右驱动轮在 URDF 中定义的关节名称。插件会通过这些名称找到对应的关节并施加力矩。<wheel_separation>: 轮距（左右轮中心之间的距离），单位为米。<wheel_diameter>: 轮子直径，单位为米。用于将轮子的转速（弧度/秒）转换为线速度（米/秒）。<max_wheel_torque>: 施加在轮子上的最大力矩，单位为牛·米(N·m)。限制电机的最大输出力。<max_wheel_acceleration>: 轮子的最大加速度，单位为米/秒²(m/s²)。用于模拟电机的物理惯性限制。<publish_odom>: 是否发布里程计信息（nav_msgs/Odometry）。<publish_odom_tf>: 是否发布 odom 坐标系到机器人基座坐标系（base_link）的坐标变换。<publish_wheel_tf>: 是否发布轮子相对于基座的坐标变换（通常用于调试或可视化轮子状态）。<odometry_frame>: 里程计坐标系的名称，通常为 odom。<robot_base_frame>: 机器人基座坐标系的名称。插件将计算从 odom 到 base_footprint 的变换。

    C++实现机器人画圆与程序退出及时停止

    src/fishbot_description/src/fishbot_circle.cpp

    /**
 * 控制fishbot画圆
 */
#include <signal.h>  // 用于信号处理
#include <chrono>    // 时间相关头文件
#include "geometry_msgs/msg/twist.hpp"
#include "rclcpp/rclcpp.hpp"
// 使用时间单位的字面量，可以在代码中使用s和ms表示时间
using namespace std::chrono_literals;

class FishbotCircle : public rclcpp::Node {
  private:
  rclcpp::TimerBase::SharedPtr timer;                                 // 定时器智能指针
  rclcpp::Publisher<geometry_msgs::msg::Twist>::SharedPtr publisher;  // 发布者智能指针
  public:
  explicit FishbotCircle() : Node("fishbot_circle") {
    // 调用继承而来的父类函数创建订阅者
    publisher = this->create_publisher<geometry_msgs::msg::Twist>("/cmd_vel", 10);
    // 调用继承而来的父类函数创建定时器
    timer = this->create_wall_timer(1000ms, std::bind(&FishbotCircle::timer_callback, this));
    RCLCPP_INFO(this->get_logger(), "fishbot开始画圆");
  }

  // 添加停止机器人运动的方法
  void stopRobot() {
    auto stop_msg = geometry_msgs::msg::Twist();
    stop_msg.linear.x = 0.0;
    stop_msg.angular.z = 0.0;
    publisher->publish(stop_msg);
    RCLCPP_INFO(this->get_logger(), "fishbot已停止");
  }

  private:
  /**
     * 定时器回调函数
     * 该函数会在定时器触发时被调用，用于发布速度命令消息
     */
  void timer_callback() {
    // 创建一个Twist类型的消息对象，用于发布速度命令
    auto msg = geometry_msgs::msg::Twist();
    // 设置线速度为0.3米/秒，沿x轴正方向前进
    msg.linear.x = 0.3;
    // 设置角速度为2弧度/秒，逆时针旋转
    msg.angular.z = 2;
    // 通过发布者对象将消息发布出去
    publisher->publish(msg);
  }
};

// 全局节点指针，用于在信号处理函数中访问
FishbotCircle* g_node = nullptr;

// 信号处理函数，在接收到中断信号时停止机器人
void signal_handler(int signal) {
  RCLCPP_INFO(rclcpp::get_logger("fishbot_circle"), "接收到中断信号，正在停止机器人...");
  if (g_node != nullptr) {
    g_node->stopRobot();
    rclcpp::shutdown();
  }
  exit(0);
}

int main(int argc, char const* argv[]) {
  rclcpp::init(argc, argv);
  auto node = std::make_shared<FishbotCircle>();
  g_node = node.get();  // 设置全局指针以便在信号处理函数中访问

  // 注册信号处理函数，处理SIGINT (Ctrl+C) 和 SIGTERM 信号
  signal(SIGINT, signal_handler);
  signal(SIGTERM, signal_handler);

  try {
    rclcpp::spin(node);
  } catch (const std::exception& e) {
    RCLCPP_ERROR(rclcpp::get_logger("fishbot_circle"), "发生异常: %s", e.what());
  }

  // 程序正常退出前也要停止机器人
  node->stopRobot();
  rclcpp::shutdown();
  g_node = nullptr;
  return 0;
}

    深度相机传感器仿真

    深度相机是一种可以获取深度信息的特殊相机，往往会配合彩色相机使用，彩色相机可以通过图像识别获取物体的像素坐标，结合深度就可以得到识别对象的三维坐标，机器人就可以针对目标做出相应操作。因为深度相机坐标系默认前方是z轴，所以我们先在URDF中添加一个虚拟部件来调整方位

    在camera.urdf.xacro中添加

    <link name="camera_optical_link"></link>
<joint name="camera_optical_joint" type="fixed">
  <parent link="camera_link"/>
  <child link="camera_optical_link"/>
  <origin xyz="0 0 0" rpy="${-pi/2} 0 ${-pi/2}"/>
</joint>
